# Third-party documents — STMicroelectronics

The two Markdown files in this directory are STMicroelectronics application
notes, converted to Markdown and otherwise unmodified.

| File | Document |
| --- | --- |
| `an2606-introduction-to-system-memory-boot-mode-on-stm32-mcus.md` | AN2606 Rev 70, *Introduction to system memory boot mode on STM32 MCUs* |
| `an3156-usb-dfu-bootloader-stm32.md` | AN3156 Rev 18, *How to use USB DFU protocol in bootloader on STM32 MCUs* |

**© STMicroelectronics. All rights reserved.**

They are **not** covered by the Apache-2.0 licence in `../../LICENSE`, which
applies to the rest of this plugin. They are included so that a citation to a
document and section can be checked from an installed copy, rather than against
a URL that moves. ST publishes both at <https://www.st.com>.

The revision matters. AN3156 first listed the STM32C0 series in its applicable
products at Rev 16, so an earlier revision's statements about that series hold
only by exclusion. Check the revision before citing either document for a part.

## What they answer

`../../skills/zephyr-platforms/references/stm32-boot-and-recovery.md` names the
sections to read for a given part. Neither document is meant to be read end to
